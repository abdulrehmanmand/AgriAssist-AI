# 🌾 AgriAssist: Farm Planning & Yield AI

AgriAssist is an AI-powered agricultural planning platform designed to maximize crop yield, prevent seed loss during seasonal monsoons, and diagnose crop diseases using computer vision.

## 🚀 Live Application
[Deployed Application Link](https://agriassist-ai.streamlit.app)

## ✨ Core Features
1. **Monsoon Sowing Planner:** Calculates optimal planting windows around heavy rainfall to prevent soil erosion and seed washout.
2. **Yield Optimizer:** Analyzes soil conditions, crop types, and fertilizer usage to deliver actionable growth strategies.
3. **Crop Disease Scanner:** Leverages Vision AI to detect plant diseases from uploaded foliage images and recommends targeted remedies.

## 🛠️ Technology Stack
- **Frontend / Deployment:** Streamlit & Streamlit Community Cloud
- **AI Core:** Google Gemini 2.5 Flash API (`google-genai`)
- **Language:** Python 3.10+
